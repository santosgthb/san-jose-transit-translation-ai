# Transit Translation: AI for Multilingual Public Transit Access

**Client:** City of San José, Public Transit Accessibility  
**Team:** Santos Sandoval, Sumit Chhabra, Brandon Daniel, Andrew Rivas, Aug–Oct 2026  
**My part:** I proposed the multilingual direction, conducted a resident interview about San José public transit challenges, contributed to the prototype's UI, and created the final project presentation.

## The problem

San José residents with limited English proficiency can have difficulty understanding transit information and communicating problems while using public transportation. Existing systems can create language barriers that make it harder for residents to ask questions, report transit issues, and receive understandable assistance.

## What we built

- Built an AI-assisted multilingual transit prototype designed to help residents communicate public transit questions and issues across language barriers.
- Designed a simple user experience where residents can submit transit-related information and receive an easier-to-understand response in their preferred language.
- Kept humans involved in decisions requiring judgment or official action; the prototype assists with communication and reporting rather than making final transit-service decisions.

## What I would do next

One gap we identified is that an AI-generated or translated response can still be inaccurate or misunderstand a resident's intent. I would build a stronger evaluation process for multilingual outputs and test the prototype with more San José transit riders across multiple languages before deploying it in a real public-service environment.
